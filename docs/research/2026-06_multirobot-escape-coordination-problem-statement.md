# L9 멀티로봇 Escape 조정 — 문제정의·설계 (Phase D 후보)

> **작성일:** 2026-06-10 · **상태:** 문제정의 초안 · **층:** L9(플릿·멀티)
> **위치:** 전체 아키텍처 §5 기여지도 — SE-MPPI의 자연스러운 확장.
> **목표:** 좁은 공유 공간에서 다수의 SE-MPPI 로봇이 **서로를 가두지 않고**, 분산적으로 **certified-safe**하게 탈출·통과.
> **인용 신뢰도:** 외부 방법은 (검색요약 기반·원문 미확인) — N0(원문 검증)에서 확정.

---

## 1. 동기 — 단일 로봇 SE-MPPI를 다수로 올리면 생기는 새 문제

SE-MPPI는 단일 로봇이 *정적/동적 장애물 속에서* 갇히지 않고 안전하게 주행하게 한다. 그런데 같은 좁은 공간(창고 통로, 교차로)에 **여러 SE-MPPI 로봇**을 넣으면 단일-로봇 설계가 풀지 못하는 문제가 생긴다:

| # | 문제 | 단일 SE-MPPI로 안 풀리는 이유 |
|---|---|---|
| M1 | **상호 로컬미니마(deadlock)** — 좁은 통로에서 마주친 두 로봇이 서로를 막아 양쪽 다 entrapment | 각자 상대를 "정적 벽"처럼 보고 탈출 시도 → 동시에 같은 방향 양보/점유로 진동 |
| M2 | **escape의 외부효과** — A의 탈출 기동이 B를 새 trap에 밀어넣음 | escape가 *자기* 진행만 고려, 타 로봇 영향 무시 |
| M3 | **상호 안전 책임 분배** — A·B 둘 다 상대를 동적장애물로 CBF에 넣으면 *양쪽이 동시에 감속/회피*해 과보수·교착 | 단일 CBF는 "내가 모두 피한다" 가정 → 책임 중복 |
| M4 | **통신 부재/지연** — 분산 환경에서 중앙 조정자 없이 일관된 결정 | SE-MPPI는 로컬 정보만 사용 |

→ **다중 로봇용 escape-safety 조정 = 새 기여**(단일 로봇 조율의 분산 버전).

## 2. 선행연구 미니서베이 (잠정 — 원문 미확인)

**(a) 분산 충돌회피(안전).**
- **ORCA/RVO**(reciprocal velocity obstacles): 각 로봇이 충돌 책임의 *절반*을 짐 → 진동 없는 분산 회피. 표준 baseline. 단, 형식적 forward-invariance·동역학 제약·deadlock 해소는 약함.
- **분산 CBF / 책임분배 CBF**: 다중 에이전트 CBF-QP에서 안전 제약을 쌍별로 나눠 부담(responsibility allocation) → 한쪽만 회피해도 안전 유지, 과보수 완화. (멀티로터·차량 사례) — *escape/deadlock과 결합은 미확인.*

**(b) deadlock 해소(진행).**
- 우선권(priority)·예약(reservation)·우향양보 규칙, 또는 perturbation으로 대칭 깸. 단, 대부분 *안전*과 별도 레이어이거나 형식 보장 없음.

**(c) Nav2 멀티로봇.** Nav2는 다중 로봇 launch(네임스페이스 분리)는 지원하나, **로봇 간 escape-safety 조정 컨트롤러는 전무**(각자 독립 Nav2). → 우리 SE-MPPI를 분산 조정으로 확장하는 배포 가능 플러그인은 미점유로 추정.

> **갭(잠정):** *분산 CBF(상호 안전, 책임분배) + 멀티로봇 deadlock escape + Nav2-native 배포*의 교집합 미점유. 특히 "상대 로봇과의 escape 책임·우선권을 CBF 게인/책임분배로 조율"은 단일-로봇 α-변조의 자연 확장으로 미발견.

## 3. 제안 — Multi-SE-MPPI (가칭)

### 3.1 핵심 아이디어
각 로봇은 **여전히 로컬·분산**으로 동작하되, 이웃 로봇에 대해:
1. **상호 책임분배 CBF** — 로봇-로봇 쌍의 안전 제약을 책임계수 $\lambda_{ij}$로 분배($\lambda_{ij}+\lambda_{ji}=1$): 각자 자기 몫만 회피 → 과보수·교착 완화, forward-invariance는 쌍별로 유지.
2. **분산 우선권 escape** — deadlock(상호 entrapment) 감지 시, 결정적 규칙(예: ID/목표거리/우선도 기반)으로 한 로봇은 *양보(hold/후퇴)*, 다른 로봇은 *escape α↑로 통과* → 대칭 깸. 양쪽이 동시에 같은 행동하는 진동 제거.
3. **이웃 인지 escape** — escape subgoal(gap) 선택 시 타 로봇 점유/예상경로를 비용에 반영(M2 외부효과 완화).

### 3.2 정보 소스 (통신 최소)
- 1차: **인지 기반**(LiDAR로 이웃 로봇을 동적장애물로 추적) — 통신 없이도 동작(SE-MPPI 트래커 재사용).
- 2차(선택): 경량 통신(자기 pose·목표·우선도 broadcast) → 책임계수·우선권을 더 정확히. 통신 두절 시 1차로 graceful degrade.

### 3.3 안전 명제 (단일 명제의 확장)
쌍별 책임분배 CBF가 각 로봇에서 $\dot h_{ij} + \alpha h_{ij} \ge 0$를 $\lambda_{ij}$ 몫으로 만족하면, **쌍 상호 forward-invariance**($h_{ij}\ge0$) 유지 → 로봇-로봇 무충돌. 우선권 escape는 α를 올려 통과를 허용하되 명제(∀α>0 유지)로 여전히 certified-safe. (증명 스케치: 단일 로봇 명제를 쌍별로 적용 + 책임합=1.)

## 5. 리스크

- **분산 일관성**: 동시 결정의 대칭/충돌 → 결정적 타이브레이크(ID 등) + 인지 지연 강건성 필요.
- **통신 가정**: 1차 인지-only로 설계해 통신 의존 최소화.
- **확장성**: 로봇 수↑ 시 쌍별 CBF·QP 비용 → 이웃 가지치기(가까운 K).
- **novelty**: N0 전까지 차별점 잠정(분산 CBF는 기성 — 차별점은 *escape·deadlock 결합 + Nav2 배포*).

---

## 6. SE-MPPI와의 관계

단일-로봇 SE-MPPI(L6/L7)가 토대다: 트래커·CBF·escape·α 조율을 **그대로 쌍별·분산으로 승격**. 즉 이 모듈은 "조율"의 *공간적 확장*(자기 안↔밖 → 로봇 간)이며, Phase C(L2 예측)가 *시간적 확장*(현재→미래)인 것과 대칭을 이룬다.
